# Imported antibiotic reference collection

Keep the imported JSON byte-identical to its attributed prototype version unless
explicitly updating sources with a new provenance manifest. All records remain
Unreviewed, clinically ineligible and non-executable. Numerical tables require an
explicit disclosure. Preserve exact product/route, jurisdiction, edition, modality,
flow, residual-function, downtime, weight-scalar assumptions and evidence gaps.
Never inherit guidance between products or turn national/foreign references into
local hospital policy. Do not import calculators, dose engines, example patient
medications/cultures, treatment selection or session-decision attachments into this
reference view. Reuse the shared patient workspace; reference browsing performs no
patient write and does not establish applicability to the patient. Keep licensed
Harrison/Sanford text outside this collection; publisher links only.
