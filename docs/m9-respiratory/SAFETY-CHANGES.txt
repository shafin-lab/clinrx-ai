Respiratory/ABG safety corrections — 23 October 2026

Applied to the concurrently added respiratory workspace. Existing source
records, migrations, databases and other modules were not rewritten by this task.

CHANGES
1. A measurement set must be selected explicitly. Newest-first sorting no longer
   silently selects a clinical sample or displays its arithmetic.
2. Loading, retrieval error or unconfirmed current evidence suppresses the
   selected calculation panel and disables sample-review controls. A caller's
   stale current=true cannot override an explicit retrieval error.
3. Scope and period placement compare complete fractional instants and offsets.
   Distinct microsecond/submicrosecond times cannot collapse into one JavaScript
   millisecond. Equivalent explicit offsets/trailing zeroes still match.
4. Blood gases require their own exact collection time for physiological period
   placement. Bounded, approximate, day-only or missing collection stays context;
   a later report/availability time cannot become a collection time.
5. Other respiratory records use their observation/performance time rather than
   their report/availability time. Conflicting raw/recorded source times remain
   unplaced instead of choosing one by convenience.
6. Legacy sample-time setting fields remain source assertions. Their presence
   does not set an independent support-alignment confirmation to true. The
   original source values remain available for inspection.

VERIFICATION METHOD
New regressions were observed failing before their fixes. An existing UI test
now explicitly selects its source before asserting the selected sample detail.
A reviewer confirmed the final delta, including the bounded-null collection case.
Executed counts, commands and source identities are in IMPLEMENTATION-VERIFICATION.json. DESIGN-VERIFICATION.json remains the historical design-only record.

APPROVED INTERFACE INTEGRATION
The user approved the four-panel overview on 23 October 2026. It is now integrated
above the existing specialist tabs, which retain source entry/history/review flows.
Specimen-specific gas concepts prevent capillary/peripheral venous values from
borrowing arterial or mixed-venous identity. The review panel summarizes the
existing matching-scope browser review; it adds no second review store.

REMAINING CLINICAL/WORKFLOW WORK
The full single-entry, cross-domain clinician workflow requires separate
verification. A combined screen is not proof of integrated clinical reasoning.

Mechanics still needs clinical reconciliation of the actual source-contract
evidence for zero-flow, leak, hold quality/duration and volume/breath pairing.
This task does not claim that the existing two confirmation booleans establish
all those conditions. Do not promote the engineering preview to patient use or
claim comprehensive CHEST/ERS/Indian Chest Society compliance from passing tests.
Other arithmetic and condition-specific pathways require the documented profile,
evidence, population, local-protocol and clinical validation work.

SUBSEQUENT SHARED-WORKSPACE CORRECTIONS
Respiratory RR/SpO2 is read directly from its original source in M7; M9, kidney
and antibiotic views expose original shared context without copying observations.
M7/M9 saved review freshness now compares the exact confirmed source pins and
domain coverage as well as scope/cutoff. Loss of culture confirmation invalidates
a queued review and makes the older note historical even at the same watermark.
Typed native timing/quality captions distinguish observation from collection.
Existing observations are grouped by measurement and ordered by source time;
lactate display drops redundant trailing zeroes while raw source values remain.

Optional chest examination and imaging capture uses the existing source owner.
A modality template alone cannot establish an imaging report: a source finding,
original narrative or explicit study status/reason is required. Blank findings
are omitted and no normal result or performed test is inferred.
