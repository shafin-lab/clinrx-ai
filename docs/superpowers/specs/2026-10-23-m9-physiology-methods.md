# M9 respiratory physiology methods

Implementation: `frontend/src/respiratory/physiology.ts`; calculation version `m9-physiology-2026-10-23-v1`; verified 23 October 2026. Pure same-record arithmetic, without disease classification or automatic treatment advice. Formula eligibility does not imply endorsement of this application by a society.

## Input contract

Each output has an explicit formula, value or null, reason, exact source `id@revision`, collection context, original measurement values/units, roles, quality, and methods. Input quality must be `usable`; unknown quality is withheld. Measured inputs must have role `measured`, except explicitly declared settings/assumptions, source predictions and source-calculated bicarbonate used for conditional Winter compensation. Duplicate concepts, censored/comparator results, absent/nonnumeric/nonfinite values, unsupported units/namespaces, incompatible roles and suspect quality withhold affected outputs. Withdrawn/invalid/unknown records, withdrawn/cancelled/pending/unknown reports, and superseded revisions withhold all outputs. Preliminary/interim records can calculate only when each relevant measurement is explicitly usable.

Supported unit namespaces: `UCUM`, `ucum`, `http://unitsofmeasure.org`. Pressure units `mmHg`, `mm[Hg]`, `kPa`; airway pressures also `cmH2O`, `cm[H2O]`; fraction/percent `1`, `%`; volume `mL`, `L`; rate `/min`, `min-1`, `{breaths}/min`; flow `L/s`, `L/min`, `mL/s`; height `cm`, `m`, `[in_i]`; coefficient `kg`; monovalent chemistry `mmol/L`, `mEq/L`; protein `g/dL`, `g/L`. No unit inferred from the display label. FiO2 is explicitly 0.21–1, never estimated from oxygen flow. Saturation must be positive and <=1; S/F and OSI are restricted further to SpO2 <=0.97. Values with inappropriate negative quantities, nonpositive denominators, impossible pressure relationships or nonpositive PBW are withheld. Legitimate negative anion gaps or A–a results are retained as arithmetic for review.

## Implemented methods

| Output IDs | Arithmetic and required evidence |
|---|---|
| `pf_ratio`, `sf_ratio` | PaO2/FiO2 (mmHg), SpO2 percent-number/FiO2 fraction (conventional dimensionless ratio). P/F requires arterial sample. Both require settings explicitly confirmed at measurement time. Venous sample type does not invalidate a separately measured pulse saturation. |
| `oxygenation_index`, `oxygen_saturation_index` | 100 × FiO2 fraction × measured MAP / PaO2 mmHg or SpO2 percent-number. Same sample-time setting gate. Arithmetic only, with no ARDS/PARDS diagnosis or severity thresholds. |
| `minute_ventilation` | Measured Vt mL × measured rate /1000, L/min; set targets cannot substitute. |
| `alveolar_ventilation` | (Vt−measured Bohr physiologic dead-space volume) × rate /1000. Dead space must be <=Vt with method `bohr_volumetric_capnography`; anatomical Fowler dead space, Enghoff estimates and weight estimates cannot substitute. |
| `predicted_body_weight`, `tidal_volume_per_pbw` | Confirmed adult; height 100–250 cm; explicitly chosen coefficient 50 kg with `ardsnet_adult_male` or 45.5 kg with `ardsnet_adult_female`. PBW = coefficient +2.3×(height inches−60). Result must be positive. Vt/PBW uses measured volume. Actual weight cannot substitute. |
| `driving_pressure`, `static_compliance` | Pplat−totalPEEP; measured Vt/(Pplat−totalPEEP). Passive conditions and occlusion confirmation required. Set PEEP cannot replace measured totalPEEP, and peak pressure cannot replace plateau. Respiratory-system compliance includes the chest wall. |
| `dynamic_compliance` | Measured Vt/(Ppeak−totalPEEP); passive conditions and total-PEEP occlusion confirmation. Includes resistive effects. |
| `airway_resistance` | (Ppeak−Pplat)/flow L/s. Confirmed passive/occlusion conditions, exact `volume_control` mode, measured flow method `constant_inspiratory_flow`. Estimate includes tube/respiratory-system resistive effects. |
| `alveolar_oxygen_pressure`, `aa_gradient` | General PAO2 = FiO2(PB−PH2O)−PaCO2[FiO2+(1−FiO2)/RQ]. Arterial gas, sample-time FiO2, explicit barometric pressure, water-vapour pressure and RQ. No sea-level, 37°C or RQ0.8 default. A−a subtracts PaO2. Negligible inspired CO2 and steady state remain explicit model assumptions. |
| `ph_description` | Confirmed adult arterial pH: <7.35 acidemia, >7.45 alkalemia, otherwise within adult arterial interval. No primary/mixed-disorder diagnosis. |
| `anion_gap`, `albumin_adjusted_anion_gap` | Measured Na−Cl−bicarbonate without potassium, from the same coherent record. Source-calculated gas bicarbonate cannot substitute for measured chemistry. Adult albumin adjustment adds2.5×(4−albumin g/dL), explicitly disclosing reference4. No universal normal AG cutoff. |
| `winter_expected_paco2` | Confirmed adult arterial acidemia and bicarbonate<24: conditional expected PaCO2 =1.5×bicarbonate+8±2, with factual above/within/below comparison to measured PaCO2. Bicarbonate may be measured or source-calculated. Applies **if metabolic acidosis is primary**; it does not establish that diagnosis. |
| `respiratory_compensation` | Confirmed adult arterial PaCO2; HCO3 baseline24, PaCO2 baseline40. Conventional acute/chronic possibilities per10mmHg: for elevated PaCO2,+1–2/+3–4; for decreased PaCO2,−1–2/−4–5. Does not infer duration or a primary process. These are conventional ranges, not exact predictions. |
| `arterial_oxygen_content`, `mixed_venous_oxygen_content`, `oxygen_delivery` | Content =1.34×Hb g/dL×co-oximetry saturation fraction+0.003×PO2 mmHg. Sample explicitly arterial or mixed venous respectively; `sao2`/`svo2` method `cooximetry`; `pao2`/`pvo2` respectively. DO2=CaO2×same-record measured CO L/min×10. SpO2 and PO2-derived saturation cannot substitute. Fixed binding/solubility coefficients and absence of major dyshemoglobins are assumptions; review functional versus fractional saturation. |
| `enghoff_dead_space_fraction`, `bohr_dead_space_fraction` | (PaCO2−mixed-expired PCO2)/PaCO2 for arterial Enghoff estimate; (measured alveolar PCO2−mixed-expired PCO2)/alveolar PCO2 for Bohr. Alveolar method `volumetric_capnography`; mixed-expired method `mixed_expired_collection` or `volumetric_capnography`. Mixed expired cannot exceed reference PCO2. End-tidal cannot substitute. Enghoff includes shunt/VQ effects; the two methods are not interchangeable. |
| `fev1_fvc_ratio` | Usable same-report measured forced manoeuvre FEV1/FVC; no reference required for arithmetic, no fixed obstruction threshold. Values require0<FEV1<=FVC. |
| `fev1_percent_predicted`, `fvc_percent_predicted`, `tlc_percent_predicted`, `dlco_percent_predicted` |100×measured/source-reported predicted value with explicit named `context.reference_equation`. No demographics or population eligibility inferred to generate a new prediction. DLCO requires exactly matching compound units (`mL/min/mmHg`, `mL/(min.mm[Hg])` or `mmol/min/kPa`); no approximate gas-volume conversion. Percent predicted does not establish normality. |

## Deliberately unavailable methods

`oxygen_extraction_ratio` cannot validate exact paired contemporaneous arterial and mixed-venous samples in this single-sample record contract. `shunt_fraction` additionally needs validated end-capillary assumptions and protocol. `transpulmonary_pressure` needs calibrated esophageal measurements and acquisition phase. `lung_function_z_score` needs a validated equation implementation/distribution and population eligibility. `sleep_indices` needs scored event series, scoring rules and valid sleep duration. `extracorporeal_gas_transfer` needs exact pre/post membrane sample identities, circuit flow and protocol. Source-reported specialist values remain displayable; the calculator does not reinterpret them.

## Sources

- [NHLBI ARDSNet FACTT protocol](https://biolincc.nhlbi.nih.gov/media/studies/factt/Protocol.pdf): primary study protocol, explicit sex-specific PBW in inches.
- [PALICC2015 consensus](https://pubmed.ncbi.nlm.nih.gov/25647235/), [PALICC-2 executive summary2023](https://pmc.ncbi.nlm.nih.gov/articles/9848214/): primary consensus; oxygenation-index arithmetic and SpO2<=97% restriction. No pediatric diagnosis/threshold is applied to adult records.
- [AARC2024 patient-ventilator assessment guideline](https://www.aarc.org/wp-content/uploads/2024/10/patient-ventilator-assessment-aarc-cpg.pdf), [original2020 respiratory-mechanics study](https://journals.physiology.org/doi/full/10.1152/japplphysiol.00059.2020): plateau, measured totalPEEP, occlusion and static mechanics.
- [ATS Annals2014 respiratory physiology](https://www.atsjournals.org/doi/pdf/10.1513/AnnalsATS.201402-058CC): ventilation and respiratory mechanics arithmetic.
- [ERS2014 gas equation methods](https://publications.ersnet.org/ers-lookup/tab-link/erj-44-04-1023-t04/514171): general versus simplified alveolar equation, pressure/humidity/RQ dependencies.
- [Figge1998 original albumin/anion-gap study](https://pubmed.ncbi.nlm.nih.gov/9824071/): albumin adjustment coefficient.
- [Albert, Dell and Winters1967 original study](https://pubmed.ncbi.nlm.nih.gov/6016545/), [Berend2014 corrected physiological assessment](https://www.nejm.org/doi/10.1056/NEJMra1003327), [current Merck adult compensation table, reviewed2025](https://www.merckmanuals.com/professional/nephrology/acid-base-regulation-and-disorders/acid-base-disorders): original citation plus current conventional formula/ranges. Winter original abstract does not expose the formula passage; accessible current clinical descriptions verify arithmetic. Acute/chronic conventions vary by source and are labeled as ranges.
- [NIOSH oxygen-transport physiology](https://www.cdc.gov/niosh/docket/archive/pdfs/NIOSH-008/0008-041003-BerndtssonG_Pres.pdf): Hb-bound/dissolved oxygen coefficients and delivery units.
- [Respiratory Care2013 dead-space measurement methods](https://rc.rcjournal.com/content/respcare/58/7/1143.full.pdf): Bohr/Enghoff differences and volumetric measurement prerequisites.
- [ERS/ATS2022 technical standard](https://publications.ersnet.org/content/erj/60/1/2101499): source reference equations, forced manoeuvre ratios, predicted-value interpretation limits. No unlabeled bronchodilator response rule is implemented because criteria differ across source/year.
