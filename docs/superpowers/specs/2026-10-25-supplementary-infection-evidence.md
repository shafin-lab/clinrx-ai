# Supplementary infection evidence: approved design

The user approved an optional, initially collapsed “Further evidence & alternatives” section below relevant NCDC infection guidance. NCDC treatment cells, comments, provenance, source files and figures remain unchanged. The supplement is reference material, not a prescription, automatic replacement or patient-specific calculation.

Use the reviewed 2023–2026 shortlist. Store each source once and each distinct clinical question once, with explicit infection/row bindings. Show verified external schedules intact, with population, source version, rationale, difference/limitations and supporting source. Context-only references must not imply that a complete alternative regimen is supplied. Avoid generic cards under unrelated infections, repeated source links, mismatched HIV/BMT or adult/neonatal schedules, old or access-limited references, JIPMER, CRRT and monograph expansion.

Use native details/summary below the existing NCDC source area; no new navigation or prescribing actions. Reset expansion when infection or clinical situation changes. No placeholder section when no relevant reference is available. Browser interactions are local and do not fetch sources, write storage or modify patient records.

Preserve original port 5246, current NCDC source bytes, both patient databases, signing material and current candidate build rollback assets. Publish the reviewed update at the existing candidate origin 5247. Mobile checks remain deferred.
