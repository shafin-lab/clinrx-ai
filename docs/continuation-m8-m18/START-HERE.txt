WHAT CHANGED IN CODE
One shared product catalog now covers routine through specialised investigations.
The existing overview uses its explicit mappings for the already supported
synthetic creatinine and circulatory laboratory/oxygen records. This replaces a
local creatinine label with a reusable catalog label; it does not create a panel UI.
All original records still go through the existing strict decoder, scope checks,
finding grouping and exact source/history opening. No stored observations are copied.
KFT/RFT aliases search the same development group; they do not map original assays.

WHAT REMAINS UNBUILT
General laboratory ingestion, a complete laboratory-result envelope, new clinical
domain storage, compatible shared microbiology loading, general Note/Report entry,
nutrition calculators, interpretation and treatment support. Recorded weight now
saves through the existing owner only under the candidate's explicit synthetic gate.
No live writes or deployment are enabled.
